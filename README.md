# Employee Management System

## About the Project
The Employee Management System is a simple, menu-driven Python mini project developed using Object-Oriented Programming (OOP) concepts. It allows users to manage employee records through a command-line interface.

## Features
- Add new employee records
- Display all employees
- Search for an employee using Employee ID
- Update employee details
- Delete employee records
- Exit the program through a menu option

## Technologies Used
- Python 3
- Object-Oriented Programming (Classes and Objects)

## OOP Concepts Used
- **Classes and Objects:** Used to represent employees and manage employee records.
- **Constructor:** Initializes employee details using `__init__()`.
- **Methods:** Perform operations such as adding, searching, updating, and deleting employees.
- **Encapsulation:** Organizes employee-related data and operations within classes.

## How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   ```bash
   python employee_management.py
   ```

## How It Works
When the program runs, it displays a menu with six options. The user can select an operation by entering the corresponding number. Employee records are stored in a list during program execution.

## Limitations
Employee records are stored temporarily in memory. The records are lost when the program is closed.
